# Financial and Authorization Invariants

Round 1 evidence rules are kept below; the **Round 2 status** column records the independent audit
(`docs/v2/ROUND-2-AUDIT.md`, `evidence/round2/`). "PG" means enforced by PostgreSQL constraints or triggers,
"Java" by application code, "Test" by a real-PostgreSQL integration test.
