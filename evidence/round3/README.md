# Round 3 Evidence

This directory holds new evidence for E4–E11. Historical `evidence/e0`–`evidence/e3` and `evidence/round2` remain untouched.

Record exact commit SHA, command, target database/cluster, raw output, independent SQL checks and honest verdict for each run. Commit major experiment pre-registration before taking measurements. Synthetic results are not production capacity claims. A missing run is `NOT_RUN`, a safety or infrastructure blocker is `BLOCKED`, and an executed failure remains in the record.

Initial baseline: `baseline/BASELINE.md`. E4 pre-registration and executed verification are in `e4/`; E5 has a pre-registration in `e5/` and will receive results only after its experiments run. E6–E11 artifacts will be added as their experiments run.
