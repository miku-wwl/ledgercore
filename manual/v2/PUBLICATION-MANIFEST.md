## 1. Build

```powershell
python manual/v2/tools/make_diagrams.py
python manual/v2/tools/gen_e12_catalogue.py
python manual/v2/tools/build.py
python manual/v2/tools/qa_pdf.py manual/dist/LedgerCore-V2-Enterprise-Banking-Reliability-Engineering.pdf
```

Toolchain: pandoc 3.8 (Markdown → HTML), Microsoft Edge via Playwright (two print passes: the first finds every
heading's page from the PDF outline, the second prints the final body with those page numbers in the table of
contents; the cover is printed separately), pypdf (merge and metadata). Code excerpts are read with
`git show <commit>:<path>`; nothing is copied from the working tree. Build scratch is in the ignored `work/book-v2/`.

## 4. Visual QA

Every page was inspected twice on contact sheets of eight pages each (`work/book-v2/sheets/`, ignored by Git):
first on the 179-page build that followed the last content edits, then on this final 180-page build. Close-ups at
about twice the sheet resolution were checked wherever a defect was suspected (PDF pages 47, 76 and 114 of the first
build; 115 and 178 of the final build). Three defects were found and fixed before the final build:

1. Table 8-1 left its caption and header row alone at the foot of a page, and Table 5-1 broke three rows plus one. A
   table with at most five body rows is now never split (`table.keep`, set by `assets/render.js`); both tables now
   print whole, directly after their lead-in sentence.
2. Appendix I printed the apostrophe in three English case titles (E12-E07, E12-E09, E12-G02) as a full-width curly
   quote. The generator now escapes Markdown punctuation, so every title prints exactly as written in `cases.json`.
3. In Fig. 21-1 the dashed "both alerts firing" marker crossed the "+65.1 s" label of the effect-pending lane; the
   label now starts just after the marker.

Accepted after review: chapter-end pages that carry only the chapter's exercises (PDF pages 49, 141 and 147), white
space left before a figure that cannot be split (for example PDF pages 127, 131 and 139), and long tables that continue
on the next page under a repeated header (Tables 3-1, 24-2 and 26-1). PDF page numbers are one higher than the printed
folio because the cover is unnumbered.

**Page count.** The first build after the content edits had 179 pages. Keeping Tables 5-1 and 8-1 whole moved the two
exercises of chapter 8 onto a page of their own, which made 180. Nothing was written to reach a page count: between
the two builds the number of extractable CJK ideographs changed by −9, which is exactly the two table header rows that
are no longer printed twice (−33) plus the running footer of the added page (+24). The 180 pages therefore sit at
the lower bound of the 180–260 target, and the last of them exists because of layout, not because of added text.

## 5. Searchability and fonts

Text, including code, is selectable and searchable: every one of the 71 code excerpts was found in the
text extracted with pdfium by the longest identifier of its anchor line, and every font carries a ToUnicode map. The
Chinese text is set in Microsoft YaHei, embedded as subsets. Font programs exist only inside the PDF; no font file is
committed or distributed separately.

## 6. Reproducibility

A second build started from an emptied build directory: the 38 diagram files and appendix I were regenerated (all 39
files byte-identical to those of the first build; 36 of the diagrams appear as numbered figures, while `fig-auth-matrix.svg`
and `fig-effect-queue.svg` are drawn by the generator but placed in no chapter), pandoc produced a byte-identical HTML file and numbering, and Edge printed
180 pages whose extracted text and rendered pixels (pdfium, scale 0.6) equal the published PDF on every
page. The two files have the same size and differ in 3,211 bytes, every one of them inside a per-run identifier: the
node IDs of the tagged-PDF structure tree (`/ID (node…)` and the ID name tree that lists them) and the `/CreationDate`
and `/ModDate` timestamps.

## 7. Limitations

- The book describes an engineering laboratory with synthetic money, people and organizations. It is not a certified
  production bank, does not claim compliance with any regulation, and contains no penetration-test result.
- Performance numbers are local single-machine observations; E3 H01 remains INCONCLUSIVE, the V10 index candidate
  remains rejected, PITR RPO/RTO remain one-run local evidence, and the toy clearing simulator says nothing about real
  interbank settlement.
- The accessibility work is a subset (no axe/WCAG audit, no screen-reader review); the UI text is English while the
  book is Chinese.
