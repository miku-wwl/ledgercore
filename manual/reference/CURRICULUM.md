# 阅读路线与课程结构

这本书跟随一次用户转账，而非按框架 API 逐项罗列。读者从金额含义和复式记账进入领域模型，再沿着请求、事务、数据库、浏览器状态和恢复路径走完。第 1–12 章解释后端与数据的一致性，第 13–16 章回到安全的 HTTP 与 React 用户旅程，第 17–20 章把性能、测试、需求演进和工程推理收束起来。

阅读时请把“确定写入”和“客户端知道写入结果”分开。前者是数据库事务的事实，后者是网络交付的事实；二者不等价，幂等恢复章节正是整本书的枢纽。

所有代码和实现说明锁定于 Git 提交 484b9ad1c70ba052849ee1a40e15e35b6d888c12。性能实验是本机 PostgreSQL 18.7 上的合成数据实验，界面截图为隔离数据库中的本地实际运行截图。书中不把演示应用描述为真实银行系统。
