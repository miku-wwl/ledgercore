# LedgerCore 产品需求

## 产品与读者

LedgerCore 是一款只处理模拟资金的银行应用，用来练习 Java 全栈应用工程与数据库交易正确性。第一读者是具有基础 Java 和 Web 知识、希望理解账本、事务、并发和前后端一致性的工程师。它不是银行核心系统，也不连接真实银行或支付网络。

## MVP 用户目标

注册并登录后，客户可以创建模拟账户、查看余额和自己的交易历史，并向另一位客户的 LedgerCore 账户转账。账户开户时获得明确标注的模拟初始资金。客户可以看到某笔转账的教学解释，但不能查看其他客户的账户资料或完整账本。

## 功能范围

| 能力 | MVP 行为 |
|---|---|
| Identity | 注册、登录、退出、当前用户查询 |
| Accounts | 创建、列出和查看自己的模拟账户；所有权由服务端验证。领域服务支持生命周期转换，但当前 MVP 没有面向客户的关闭/暂停/恢复 API |
| Initial funding | 开户时由模拟储备资产账户生成一笔有对手方的平衡分录 |
| Transfers | 在两个不同的内部账户间转账；不支持外部路由 |
| Ledger | 每个已提交凭证至少两条 Posting，借贷按币种平衡；已过账记录不可变 |
| Balance | 展示由账本生成的 NZD 余额投影；对账可重建与比较 |
| History | 查询本人拥有账户的分页交易历史 |
| Idempotency | 持久键、规范化请求指纹、成功回执及原键重放 |
| Recovery | 网络结果不明时，浏览器保留原请求和原键以重新确认同一操作 |
| Dashboard | React 页面明确标识“模拟银行”，呈现加载、空、错误和窄屏状态 |

开户初始金额固定为 NZD 1,000.00，不由客户端任意铸造。更改该值属于影响资金来源的业务决策，必须保留来源账目和审计记录。

## 业务边界

唯一币种是 NZD，最小单位为分。MVP 不处理真实资金、真实账户、支付网关、结算网络、外汇、贷款、信用卡、利息、监管认证、区块链、AI、Kubernetes、Terraform 或无明确需求的微服务拆分。所有用户页面始终显示模拟用途。

## 验收结果

P0 验收的是领域语义、数据模型、架构边界和可验证规则，不等于应用已实现。应用验收必须逐阶段引用真实构建、数据库、测试和 CI 结果；没有执行的内容标记 NOT_RUN。

## 阅读目标

完成最终教材后，读者应能追踪一次转账中的借贷方向、账户锁、数据库提交、持久幂等回执和浏览器未知结果，并能指出这些保证的实现边界。教材只在 P5 应用验收后开始正式出版。
